# 硬件与启动链

## SoC

HiSilicon **Hi3798MV100**，4× Cortex-A7（ARMv7-A，NEON + VFPv4），12 V 单电源。
运营商 IPTV 机顶盒常见方案（本机为华为 EC6108V9C 四川电信 CA 版）。

**没有的东西**（不要指望）：

- 硬件视频编解码（mainline 无 VPU 驱动，Jellyfin 之类跑不了）
- 千兆网口：MAC 是 `hisi-femac`（Fast Ethernet），且 PHY 挂在 **MII** 上，物理上限 100 Mbps
- 温度传感器、DVFS：内核看不到温度，CPU 定频
- 1.8 V 电平切换：eMMC/SD 只能跑 3.3 V 模式

## 原厂分区表

命令行的 `blkdevparts` 还原了原厂 16 个分区：

```
mmcblk0:1M(fastboot),4M(bootargs),16M(recovery),1M(deviceinfo),
        4M(baseparam),4M(pqparam),4M(logo),16M(fastplay),8M(misc),
        24M(factory),12M(kernel),8M(iptv_data),340M(backup),
        340M(cache),520M(system),-(userdata)
```

本项目把 Debian 装在 **userdata**（`mmcblk0p16`，6 GB）上，原厂 `system`/`backup` 分区原样保留。

## 启动链

```
BootROM
  ├─ eMMC 上的 fastboot（签名件）→ 高安版需要短接 J16 才进恢复模式
  └─ 或 U 盘上的 fastboot.bin（bootrom 回落）

fastboot 从 U 盘 FAT 读 uImage（zImage + 追加 DTB）
  → 内核解压、ATAG_DTB_COMPAT 把 bootargs 注入 DT
  → init=/usr/local/sbin/ec-init.sh（见 config/boot/ec-init.sh）
      · 挂 U 盘 FAT，把 dmesg / 分区信息追加到 BOOTREPORT.TXT
      · exec /sbin/init
  → systemd → Debian
```

### 免短接

eMMC 上 `p1`（fastboot 分区）的前 1 MB 清零后，bootrom 判定 eMMC 上的 fastboot 不可信，自动回落到 U 盘恢复模式——**不用再短接 J16**。

代价：eMMC 侧的 Android 引导失效（盒子不能再启动安卓）。回滚方式是把 `p1.bin` dd 回去。

### 内核参数

```
console=ttyAMA0,115200 console=tty0 consoleblank=0
root=/dev/mmcblk0p16 rootfstype=ext4 rootwait rw
net.ifnames=0 mem=1G mmz=ddr,0,0,48M vmalloc=500M
init=/usr/local/sbin/ec-init.sh
```

- `console=tty0` 让内核日志上 HDMI
- `consoleblank=0` 关掉 10 分钟自动黑屏
- `mmz` 是海思多媒体内存区，保留 48 MB 给 VO/DMA
- `blkdevparts` 决定分区节点名，本机与 dearjoe 的通用镜像不同（baseparam 在 22 M、pqparam 在 26 M）

## 设备树

板级 DTS：`dts/hi3798mv100-ec6108v9c.dts`（node 结构对照 `hi3798.dtsi` / `hi3798mv100.dtsi`）。

关键节点：

| 节点 | 地址 | 说明 |
|---|---|---|
| `mmc@9830000` | `&emmc` | eMMC，aliases: mmc0 → mmcblk0 |
| `mmc@9820000` | `&sd` | SD 槽，aliases: mmc1 → mmcblk1 |
| `ethernet@9840000` | `&eth0` | `hisilicon,hisi-femac-v2`，`phy-mode = "mii"` |
| `&hdmi` / `&vo` | — | histb DRM 驱动 |

> aliases 很重要：不写的话插拔顺序会让 mmcblk0/mmcblk1 漂移，`root=` 会指错设备。
